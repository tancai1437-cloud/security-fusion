# Skill 测试体系

当前先接入可重复排程和跨方案一致的调用统计，复用已有本地 DSH 容器测试驱动。这里的测试计划不等于正式实测已完成；自动运行四组、私有题目验收器和进程级数据隔离仍待接通验收。

已执行的同模型改进循环另见 [2026-10-06 实测记录](../references/reliability-cycle-2026-10-06.md) 与 [脱敏指标](reliability-20261006.json)。它们包含失败样本，但不是下面四组方案的比较成绩。

## 首轮配置

[pilot.json](pilot.json) 定义四类任务：Web/API、JS/源码、多节点压缩/中断恢复、同项目双会话隔离。四组分别是原生 DSH、只有 security-fusion 文件、security-fusion 加宿主适配器、reverse-skill。每题两次，计划 32 轮；先通过小规模真实工具预检再决定是否全部运行。

同一配对使用相同模型及设置、底层工具/MCP、题目变体与时间/token 上限，每组重建环境。跨组穿插顺序，避免先跑完一个版本才跑另一个。reverse-skill 按其正常接入使用，不要求走 fusion 工具；不能满足共同工具能力时标为不可比较。各题预算由实测预检确定，不沿用短冒烟时间来证明长任务能力。

```bash
python scripts/prepare_benchmark.py --seed 1 --output work/benchmark-pilot
python scripts/prepare_benchmark.py --mode natural --seed 1 --output work/benchmark-discovery
```

这两个命令只产生 JSON 排程和 Markdown 计划，不调用模型、部署容器或发起目标请求。自然发现与显式唤醒分别运行；它们不是同一批样本的两种分数。已有输出目录不会覆盖。

## 取证与评分

- DSH 执行靶场交互；评测器负责部署、被动采集、离线验收。模型声称成功、报告文件存在、进程退出码 0，都不是成功证明。
- 工具统计从宿主的真实 `tools/result` 观察生成。直接调用与嵌套调用均计入；共同能力只统计冻结工具清单内的底层调用，避免把包装器和叶子调用相加。
- 压缩与重启必须实际发生并有事件证据。下游节点必须引用有效前置产物；无理由重跑、必要对照和环境变更后的复测分别评审。
- 目标成功按私有验收器核对。验收器先用正例、阴性/修复样本验证；答案、其他运行数据与评分后台必须在受测 Agent 无权访问的位置。只写禁止读取的提示语或分目录不算隔离。
- 结果、过程、成本分开报告。保留所有尝试的分母；外部额度/容器故障、Agent 执行失败、未评分分别列出。故意注入的工具故障属于恢复测试，不能自动从能力成绩中剔除。
- 保留提供商原始 usage 字段，不把 cache 与 input 字段盲目相加。价格未核实时不估算人民币，也不宣称金额硬限额。正式调用先确认总预算并接入提供商价格或预付硬上限。
- 原始记录私有保存，公开报告仅包含必要脱敏证据。不导出密钥、身份令牌、完整模型内部推理。

离线审计已有轨迹：

```bash
python scripts/evaluate_dsh_trace.py /path/to/trace.jsonl --leaf-tool mcp__lab_a__http_request --output /path/to/metrics.json
```

`observed_tool_calls` 包含全部宿主工具结果；`shared_leaf_calls` 只含明确提供的共同底层工具。它们衡量工具使用，不代表检查正确或任务完成。旧轨迹缺少执行 ID 时保留原始观察条数并标注，不能按参数相同去重，否则会误删真实重复调用。新驱动需记录 `session`、注册表 token 对应的唯一 `execution_id`，重放同一观察才能安全去重。

## 用户需要提供什么

本轮已获准使用 OpenCode 免费模型，并以 Space Bunny Free 完成上述改进循环；没有以 Qwen 27B 执行。正式四组比较还需确定场景与总预算、完成私有验收器隔离，不能把这轮记录当作对照成绩。已有 DSH、容器骨架和参考 Skill 可复用，题目、部署、复核和报告由评测器负责人完成；密钥从安全配置读取，不通过聊天收集。
